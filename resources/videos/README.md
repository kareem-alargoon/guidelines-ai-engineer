# 🎥 Transcripts الفيديوهات

عشان أقدر أشرح الفيديو جزء جزء بالـ timestamps، محتاج الـ transcript بتاعه.

**إزاي تجيبه من YouTube:**
1. افتح الفيديو، ودوس **…more** تحت العنوان.
2. انزل لآخر الوصف ودوس **Show transcript**.
3. هيظهر الكلام كله على الجنب **بالـ timestamps**. علّم عليه كله وانسخه.
4. الزقه في ملف Markdown هنا.

**شكل الملف:**
```markdown
# Andrej Karpathy — Intro to Large Language Models
https://www.youtube.com/watch?v=zjkBMFhNj_g

0:00
hi everyone so recently I gave a 30-minute talk ...
```

**التسمية:** `<step>-<author>-<short-title>.md`، مثال: `01-karpathy-intro-to-llms.md`
